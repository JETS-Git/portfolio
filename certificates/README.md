Put certificate PDFs here that you are happy for anyone to see, then set the matching entry's
"certificate" in data/cpd.json to e.g. "certificates/nhet-sim-c1.pdf".

Before adding one, check it shows no Ahpra registration number, date of birth, address or student/staff ID.
Never put payslips, receipts, transcripts, rosters or emails here: this folder is public.
