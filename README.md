# Phil Johnson RN — E-learning Portfolio

Interactive portfolio of nursing e-learning projects, each documented as a design decision record (problem, options weighed, rationale, outcome).

Single static page: `index.html`. No build step.

- **GitHub Pages:** Settings → Pages → Deploy from branch `main`, folder `/ (root)`
- **Render:** New → Blueprint → select this repo (`render.yaml` defines a static site)
- **Edit content:** case studies live in the `CASES` array near the bottom of `index.html`
